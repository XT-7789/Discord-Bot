# Readable navigation and Finance

Main Menu keeps four primary destinations, each with a heading, a short English description and a direct button. Page titles use headings instead of small inline code. Native Discord controls retain their platform-defined size.

Finance shows Wallet and Bank separately, with Deposit and Withdraw directly below. Transfers reuse the existing banking rules and refresh the original Finance message with the updated balances and a success notice. Assets and Exchange remain accessible.

Shared navigation includes Back, Menu and Help where relevant; Close has a separate row. Active Blackjack retains its existing explicit exit flow. Component counts remain within Discord's 40-component limit.

Offline integration coverage checks all player pages, transfers in both directions, insufficient funds and in-place results. No live Discord login is used in these tests.
