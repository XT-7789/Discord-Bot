# X BOT Beta 1.4A — Levels & XP

- Message XP with editable minimum, maximum, and per-user cooldown.
- Voice XP awarded once per active minute; self-deafened and AFK users do not earn it.
- Editable ignored channels and roles.
- All-time and weekly XP, activity source totals, level, server rank, and leaderboard.
- Editable default level-up announcement and per-reward custom announcements.
- Dashboard reward-role editor using Discord role mentions or IDs.
- `Permanent` rewards are kept forever. Use this for Levels 2–5.
- `Title / Replace` rewards remove the previous title when a higher title is earned. Use this after Level 5 for Active, Elite, Senior, Mythic, Titan, Ascendant, and Legend.
- Commands: `/rank`, `/level_leaderboard`, and `/level_rewards`.
- Existing X BOT economy, mining, and war data is preserved.
- A pre-upgrade database backup is stored at `backups/xwar-before-beta-1.4A.db`.
